# Visual verification

The desktop preview was captured at 1280×720 for `/`, `/app/tasks`, and `/app/agents`. The rendered experience shows the intended dark AI operating system aesthetic: persistent navigation, cyan/lime system accents, glassy cards, responsive task rows, and agent cards with clear status and metrics. The overview places the main orchestration input above active goals and live activity, while tasks and agents have dedicated views.

The mobile preview at 375×812 collapses navigation behind a menu button, keeps the header compact, wraps the orchestration prompt and suggestion chips cleanly, and preserves readable goal cards without horizontal overflow.
